Express.js is a minimal, unopinionated web framework for Node.js — it's the most widely used choice for building REST APIs and web servers in the Node ecosystem.

**Key features:**

- **Routing** — define endpoints for each HTTP method (GET, POST, PUT, DELETE...)
- **Middleware** — functions that run before a request reaches your route handler (auth checks, logging, parsing JSON body, etc.)
- **Minimal & flexible** — doesn't force a specific project structure, you organize it your way
- **Huge ecosystem** — integrates smoothly with tools you already use like MongoDB and Prismas
